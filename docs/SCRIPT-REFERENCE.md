# Script reference

## Entry points

These are source-checkout paths. The release ZIP generated by
`scripts/windows/build-package.ps1` flattens the deployment and detector
entrypoints to its root for MDM and RTR execution.

| Script | Platform | Scope | Use when |
|---|---|---|---|
| `scripts/windows/install.ps1` | Windows | Current user | An interactive developer configures one workstation profile. |
| `scripts/unix/install.sh` | Linux/macOS | Calling user | An interactive developer configures one workstation profile. |
| `scripts/windows/deploy.ps1` | Windows | Machine and eligible user profiles | Intune, Falcon RTR, SCCM, or a local administrator configures a fleet endpoint. |
| `scripts/unix/deploy.sh` | Linux/macOS | Machine and eligible user profiles | MDM, SSH, cron, or root configures a fleet endpoint. |
| `scripts/unix/Test-AgentShieldManaged.sh` | Linux/macOS | Machine managed controls | MDM or RTR validates the Unix managed layer without inspecting user profiles. |

Do not use `install.ps1` from SYSTEM. Use `deploy.ps1 -Force` for SYSTEM,
Intune, Falcon RTR, and other non-interactive Windows sessions.

## Package build

`build-package.ps1` always creates `agent-shield.zip`, the endpoint deployment
payload. Optional integration flags produce a second archive named
`agent-shield-integrations.zip`; it is for operator-side import or distribution,
not endpoint staging.

| Switch | Archive | Contents |
|---|---|---|
| None | `agent-shield.zip` | Windows deployment runtime. |
| `-IncludeShell` | `agent-shield.zip` | Adds Linux/macOS runtime and managed detector. |
| `-IncludeFalconTemplates` | `agent-shield-integrations.zip` | Falcon Fusion v3 templates, sanitized mocks, custom scripts, schemas, and guide. |
| `-IncludeGpo` | `agent-shield-integrations.zip` | VS Code GPO scripts, policy, and guide. |

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows\build-package.ps1 `
  -OutDir .\dist -Force -IncludeShell -IncludeFalconTemplates
```

## Shared arguments

| Argument | Windows | Unix | Effect |
|---|---|---|---|
| Preview | `-DryRun` | `--dry-run` | Evaluates the plan without modifying configuration or creating a transcript. |
| Target selection | `-Only <selectors>` | `--only <selectors>` | Limits AI targets. Values can be comma-separated. `all` is the default. |
| Managed layer | `-Only managed` | `--only managed` | Applies only machine-managed targets. |
| Skip scanners | `-SkipTools` | `--skip-tools` | Defers gitleaks, Semgrep, and Trivy installation. |
| Skip VS Code | `-SkipVSCode` | `--skip-vscode` | Defers VS Code extension installation. |
| Machine output | `-OutputMode Console|Json|Quiet` | `--output-mode Console|Json|Quiet` | `Console` is interactive; `Json` emits events; `Quiet` emits only the final JSON result. |
| List targets | `-ListTargets` | `--list-targets` | Lists manifest targets and exits without changes. |

`-Only` filters AI configuration only. Git hooks, scanner tools, and VS Code
extensions remain separate layers controlled by their dedicated flags.

## Install scripts

```powershell
# Windows: current user, plan only
powershell -ExecutionPolicy Bypass -File .\scripts\windows\install.ps1 -DryRun -SkipTools -SkipVSCode

# Windows: apply current-user Codex configuration
powershell -ExecutionPolicy Bypass -File .\scripts\windows\install.ps1 -Only codex -SkipTools -SkipVSCode
```

```bash
# Linux/macOS: current user, plan only
sudo bash scripts/unix/install.sh --dry-run --skip-tools --skip-vscode

# Linux/macOS: apply current-user Codex configuration
sudo bash scripts/unix/install.sh --only codex --skip-tools --skip-vscode
```

`install.sh` resolves the invoking user when run with `sudo`; it does not write
user configuration into `/root`. A real Unix install creates a private user
transcript at `~/.local/state/agentshield/agent-shield-install.log`.

## Deploy scripts

Deploy is non-interactive only with an explicit force flag. This prevents a
remote responder from silently treating an unanswered prompt as success.

```powershell
# Windows MDM/RTR: fast configuration pass
powershell -ExecutionPolicy Bypass -File .\scripts\windows\deploy.ps1 -Force -SkipTools -SkipVSCode -OutputMode Json

# Windows: managed layer only
powershell -ExecutionPolicy Bypass -File .\scripts\windows\deploy.ps1 -Force -Only managed -SkipTools -SkipVSCode
```

```bash
# Linux/macOS MDM/SSH: fast configuration pass
sudo bash scripts/unix/deploy.sh --force --skip-tools --skip-vscode --output-mode Json

# Linux/macOS: managed layer only
sudo bash scripts/unix/deploy.sh --force --only managed --skip-tools --skip-vscode
```

Real deployment transcripts are `%SystemRoot%\Temp\agent-shield-deploy.log`
on Windows and `/var/log/agentshield/agent-shield-deploy.log` on Linux/macOS.

## Verification

`Test-AgentShieldManaged.ps1` and `Test-AgentShieldManaged.sh` are the
platform-native managed-layer detectors. They check machine-managed enforcement
only, emit one structured result, and exit `0` when compliant.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\windows\Test-AgentShieldManaged.ps1
```

```bash
bash ./scripts/unix/Test-AgentShieldManaged.sh --output-mode Quiet
```

On Linux/macOS, use the Python verifier with the profile to inspect:

```bash
sudo python3 tests/verify-install.py --home /home/<user> --expect-managed --output-mode Quiet
```
