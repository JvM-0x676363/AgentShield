# Code of Conduct

## Our commitment

We commit to a respectful, professional, and inclusive community. Harassment,
discrimination, threats, or publication of personal information are not
acceptable.

## Expected behavior

- Focus feedback on code, policy, and evidence.
- Respect privacy and do not share credentials, customer data, or personal
  contact details.
- Report security issues through the private process in `SECURITY.md`.

## Enforcement

Project maintainers may remove content, reject contributions, or restrict
participation when this code is violated. Report concerns privately to a
maintainer through an agreed channel.
