# Security Policy

## Supported versions

Security fixes are made on the default branch. Use the latest revision before
reporting an issue.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, credential exposure,
or bypass of a security control.

Use GitHub private vulnerability reporting when it is enabled for this
repository. If it is not available, contact the repository maintainer through
an agreed private channel. Include a minimal reproduction, affected revision,
impact, and suggested mitigation. Do not include real secrets, customer data,
or production logs.

## Scope

Reports are in scope when they concern AgentShield source code, distributed
policies, installers, validation logic, or documentation that could cause an
unsafe deployment. Third-party agent behavior outside the configuration
surface documented by this repository may be triaged as upstream.
